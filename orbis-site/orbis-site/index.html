Sécurités intégrées

Permissions

Les commandes ne sont visibles que par les membres ayant la permission adéquate.

Hiérarchie

Impossible de sanctionner un membre plus haut placé, le propriétaire ou le bot.

Vérifications

Permissions du bot contrôlées avant chaque action, avec un message clair.

Installation

Prérequis : Node.js 18 ou plus récent.

  1. Créer le bot sur le portail développeur Discord, copier l’Application ID (CLIENT_ID) et le token (DISCORD_TOKEN).
  2. Inviter le bot avec les scopes bot et applications.commands, puis placer son rôle au-dessus de ceux qu’il gère.
  3. Installer et configurer : npm install, puis remplir le fichier .env.
  4. Enregistrer les commandes avec npm run deploy, puis lancer avec npm start.
cd discord-bot
npm install
cp .env.example .env
npm run deploy
npm start

Hébergement 24h/24

Un bot a besoin d’un processus Node.js permanent (pas de service serverless).

Le plus simple, sans ligne de commande. Poussez le projet sur GitHub, créez un projet Railway depuis votre dépôt, ajoutez les variables DISCORD_TOKEN, CLIENT_ID et GUILD_ID, puis utilisez npm run deploy && npm start. Ajoutez un volume sur /app/data pour conserver les avertissements. Chaque git push redéploie le bot.

git clone https://github.com/VOTRE_PSEUDO/discord-bot.git
cd discord-bot
npm install --omit=dev
npm run deploy
sudo npm install -g pm2
pm2 start ecosystem.config.js
pm2 save && pm2 startup
docker build -t discord-bot .
docker run -d --name discord-bot --restart unless-stopped \
  --env-file .env -v discord-bot-data:/app/data discord-bot

Les panels de type Pterodactyl fonctionnent aussi : envoyez les fichiers sans node_modules, définissez les variables d’environnement et utilisez npm run deploy && npm start comme commande de démarrage.

Permissions insuffisantesRemontez le rôle du bot au-dessus du rôle ciblé.
